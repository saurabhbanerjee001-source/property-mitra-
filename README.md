# Property Mitra Simple Starter
Easy mobile-first Hindi/English property listing app.

Features: one simple form, Sell/Rent/Buy mode buttons, city and area, price, contact, optional photo, search/filter by city, WhatsApp contact and backup export.

IMPORTANT: This version stores listings only in the same browser on the same phone. It does not yet have shared database, login, featured payments or paid lead management. To let all users see listings, connect a shared database and secure permissions later.

Publish for free: upload index.html, manifest.webmanifest and sw.js to the root of a GitHub repository. Repository Settings > Pages > deploy from branch main and /(root). Open the HTTPS URL on Android Chrome.
